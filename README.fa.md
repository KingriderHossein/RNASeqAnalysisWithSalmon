# بازتحلیل RNA-seq با Salmon

**بازتحلیل داده‌های سرطان پروستات GSE89223، با ثبت هویت نمونه‌ها، مراحل اعتبارسنجی و مقایسه با مقالهٔ اصلی.**

[English](README.md) · [راهنمای شروع](docs/GETTING-STARTED.md) · [فهرست مستندات](docs/README.md) · [فهرست گزارش‌ها](docs/reports/README.md) · [راهنمای مشارکت](CONTRIBUTING.md)

این پروژه از مسیر «Salmon، سپس tximport و DESeq2» استفاده می‌کند. نتایج با مسیر «STAR، سپس HTSeq و edgeR» در مقالهٔ اصلی مقایسه می‌شوند.

**وضعیت علمی:** نتایج محاسباتی و مقایسه با مقاله موجود است؛ پذیرش زیستی و علمی مرحلهٔ G9 همچنان به بررسی نیاز دارد. موفقیت آزمون‌های مخزن به معنای تأیید زیستی نتایج نیست.

## داده‌ها و پرسش پژوهش

دیتاست شامل ۳۲ نمونهٔ بافت پروستات FFPE است که با دستگاه Ion Torrent Proton به‌صورت single-end توالی‌یابی شده‌اند. داده‌ها از نوع RNA کل با حذف rRNA هستند؛ بنابراین نباید آن‌ها را معادل دقیق mRNA-seq با انتخاب Poly(A) دانست.

مرجع اصلی، ژنوم GRCh37.p13 و حاشیه‌نویسی جامع GENCODE v19 است. رونوشت‌های غیرکدکننده نیز در مرجع حفظ می‌شوند.

| ویژگی | مسیر A | مسیر B |
| :--- | :--- | :--- |
| هدف | مقایسه با جمعیت نهایی مقاله | تحلیل حساسیت با طراحی جفت‌شده |
| نمونه‌ها | ۱۰ تومور و ۱۲ کنترل | ۹ جفت تومور و بافت مجاور |
| طراحی آماری | <code dir="ltr">~ group</code> | <code dir="ltr">~ patient + condition</code> |

این دو مسیر نمونه‌های مشترک دارند و دو مجموعهٔ مستقل برای اعتبارسنجی نیستند. تعریف نمونه‌ها در [فهرست نمونه‌ها](metadata/derived/GSE89223_sample_manifest.tsv) و [راهنمای منشأ داده‌ها](metadata/README.md) ثبت شده است.

براساس [خلاصهٔ علمی ۹ اکتبر ۲۰۲۶](docs/reports/GSE89223-final-advisor-scientific-summary-2026-10-09.md):

| شاخص | مقدار |
| :--- | ---: |
| خروجی‌های معتبر Salmon از نظر ساختاری | ۳۲ از ۳۲ نمونه |
| ژن‌های معنادار مسیر A | ۲٬۰۹۳ |
| ژن‌های معنادار مسیر B | ۱٬۸۵۰ |
| ژن‌های معنادار مشترک مسیر A و مقاله | ۱٬۷۳۶ |
| بازیابی ژن‌های معنادار مقاله | ۵۱٫۳۰٪ |

آستانهٔ اصلی، مقدار p تعدیل‌شده با روش BH کمتر از ۰٫۰۵ است. نرخ پایین نگاشت به رونوشت‌ها و هشدارهای کیفیت باید در تفسیر لحاظ شوند. تفاوت دو پایپ‌لاین را نمی‌توان فقط به Salmon نسبت داد.

## از کجا شروع کنم؟

برای خواندن نتایج، [گزارش تعاملی](docs/dashboard/index.html) و [خلاصهٔ علمی](docs/reports/GSE89223-final-advisor-scientific-summary-2026-10-09.md) را باز کنید. برای بررسی مراحل، از [فهرست مستندات](docs/README.md) استفاده کنید.

برای دریافت کد و بررسی فایل‌های مخزن:

```bash
git clone https://github.com/KingriderHossein/RNASeqAnalysisWithSalmon.git
cd RNASeqAnalysisWithSalmon
python3 scripts/check_repository_v1.py
```

**بازتولید کامل هنوز یک دستور آماده ندارد.** چند اسکریپت به مسیرهای ثابت رایانهٔ اجراکننده وابسته‌اند و ثبت کامل محیط و خروجی‌های لازم برای بازتولید باید تکمیل شود. پیش از اجرا، [راهنمای شروع](docs/GETTING-STARTED.md) و [محدودیت‌های بازتولید](docs/REPRODUCIBILITY.md) را بخوانید.
