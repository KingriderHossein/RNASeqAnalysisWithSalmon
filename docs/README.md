## Where status lives

- [Issues](https://github.com/KingriderHossein/RNASeqAnalysisWithSalmon/issues) own unresolved work and gate acceptance.
- [Pull requests](https://github.com/KingriderHossein/RNASeqAnalysisWithSalmon/pulls) and commits identify changes.
- [Repository checks](https://github.com/KingriderHossein/RNASeqAnalysisWithSalmon/actions/workflows/repository-checks.yml) report static validation.
- Dated reports record observations for a specific run. They do not replace current Issue state.

The architecture's target layout includes some future paths. Use the [root repository map](../README.md#repository-map) for the directories that currently exist.
